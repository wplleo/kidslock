# 儿童锁屏 · 电视认字锁屏

一款专为小米电视（Android TV）设计的儿童锁屏应用。

## 功能

- **开机自启**：电视开机后自动启动计时（默认开启）
- **后台默认运行**：无需手动操作，开机即按设定时长自动开始倒计时
- **定时锁屏**：15/30/45/60/90/120 分钟六档可选，到时自动锁屏
- **重启仍锁**：锁屏后即使关机重启，电视仍保持锁屏状态
- **认字解锁**：答对五年级水平汉字拼音才能解锁
- **家长PIN**：家长可用 PIN 码快速解锁（默认 1234）
- **手机控制**（v1.1 新增）：同一 WiFi 下用手机浏览器远程查看状态、锁屏/解锁、改时长、临时加时、改 PIN/settings，无需安装手机 App、无需联网或服务器
- **扫码即用 + 桌面图标**：电视设置页「手机扫码控制」区块显示二维码，手机扫一下直接打开；控制页可「添加到主屏幕」，之后从手机桌面一键进入
- **亮屏自动开始倒计时**（v1.2.0 新增，默认关闭）：电视开机或息屏再亮屏，自动开始新一轮倒计时；计时中亮屏不重置、锁屏中亮屏不解锁，孩子按电源键无法续时间。电视设置页和手机控制页都能开关

## 安装方法

### 方法一：U盘安装（推荐）

1. 如果之前安装过旧版，建议先在电视上卸载旧版（防止旧版入口残留）
2. 将新的 `kidslock-release.apk` 复制到 U盘
3. U盘插入小米电视 USB 口
4. 在电视上打开「高清播放器」或「文件管理」
5. 找到 U盘中的 apk 文件，点击安装
6. 安装前需在「设置 → 账号与安全」中开启「允许安装未知来源应用」

> **提示**：安装完成后，在电视桌面或「全部应用」中找「儿童锁屏」图标。如果找不到，重启一次电视即可。

### 方法二：adb 安装

```bash
adb connect <电视IP>:5555
adb install kidslock-release.apk
```

## 使用流程

1. **首次打开**：从电视桌面或「全部应用 / 应用中心」找到「儿童锁屏」图标打开
2. **设置参数**：
   - 开机自启：已开启（默认）
   - 亮屏自动开始倒计时：默认关闭，需要时手动开启
   - 观看时长：选择 15/30/45/60/90/120 分钟（默认30分钟）
   - 解锁题数：3/5/10 题连续答对（默认3题）
   - 家长PIN：默认 1234，建议修改
3. **开始计时**：按「开始计时」按钮
4. **自动锁屏**：时间到自动弹出锁屏界面
5. **认字解锁**：
   - 屏幕显示一个五年级水平汉字
   - 4个拼音选项，用遥控器方向键选择，按确认键提交
   - 答对继续，答错重置计数
   - 连续答对指定题数后自动解锁
6. **家长解锁**：在锁屏界面选「家长解锁」，输入4位PIN码

## 亮屏自动开始倒计时（v1.2.0）

电视设置页「参数配置」里多了一个开关：**亮屏自动开始倒计时**（默认关闭，不改变老版本行为）。打开后：

- 电视**开机**、或按遥控器**息屏后再亮屏**，只要当前没在计时也没锁屏，就自动开始一轮倒计时
- 开启开关的当下若没在计时，也会立刻起一轮，避免「开了没反应」
- 手机控制页「参数配置」里同样能开关，并且状态栏会显示当前开关状态

**防绕过规则**（这个功能的重点）：

| 亮屏时的状态 | 行为 |
| --- | --- |
| 已锁屏 | **什么都不做**，绝不会因为亮屏变相解锁 |
| 计时中 | **不重置倒计时**，继续按原来的剩余时间走；孩子按电源键息屏再亮屏无法续命 |
| 计时中但时间已到（服务被系统杀过） | 补拉起计时服务执行锁屏，仍然不重置 |
| 未锁屏 + 未计时 | 开启新一轮倒计时 |

实现上 `ACTION_SCREEN_ON` 不允许在 Manifest 里静态注册，所以单独跑一个只在开关打开时才存在的前台服务 `ScreenOnService` 动态监听；它只依赖 `PrefManager` 和 `LockService`，与手机控制完全解耦，服务起不来也不会影响核心锁屏。

> 想恢复「手动按开始计时」：关掉这个开关即可。停止计时后要等下一次亮屏才会重新启动倒计时。

## 手机控制（v1.1）

电视端内置一个轻量网页服务，手机不需要装任何 App，浏览器打开即用。

### 独立运行与手机控制的关系（重要）

**锁屏功能完全独立，不依赖手机、不依赖网络、不依赖手机控制服务。** 手机控制只是一个可选的附加通道：

| | 独立运行部分 | 手机控制部分 |
| --- | --- | --- |
| 组件 | `BootReceiver`、`LockService`、`LockScreenActivity`、`ScreenOnService`、`PrefManager`、`CharacterBank` | `RemoteControlService`、`ControlHttpServer`、`assets/` |
| 依赖 | 仅本地 SharedPreferences + 前台服务 | 需要局域网 + 家长同意开启 |
| 关掉/断网/服务挂了 | **照常工作**：开机自启、定时锁屏、重启保持锁屏、认字解锁、HOME 键防绕过 | 不可用，但不影响左边 |

设计上的保证：

- 依赖是**单向**的：只有手机控制去调用锁屏服务，锁屏核心代码不引用任何手机控制类
- `BootReceiver` 里启动手机控制服务用 `try-catch` 包住，启动失败不会中断后续锁屏/计时逻辑
- 设置页的手机控制开关、地址显示、二维码生成失败同样不影响锁屏
- 电视没联网时通知会提示「手机控制暂不可用（锁屏功能正常）」，而不是显示无效地址
- 锁屏状态存在本地，重启电视后自动恢复，全程不需要网络

> 实测（TV 模拟器）：设为锁屏后真重启，全屏锁屏覆盖层自动弹出、`LockService` 常驻；关闭网络后锁屏状态和服务依然保持。

### 连接步骤

1. 手机和电视连**同一个 WiFi**（电视插网线、手机连同一路由器的 WiFi 也可以）
2. 在电视上打开「儿童锁屏」设置页，点顶部的「手机扫码控制 → 点此查看二维码」一键跳到二维码区块（或直接往下滚），会显示**二维码**和控制地址（例如 `http://192.168.1.8:8080`）
3. **手机扫这个二维码**，浏览器直接打开控制页，不用手输网址
   - 电视通知栏也会常驻显示这个地址
   - 设置页有「复制控制地址」按钮，方便发到手机
4. 输入家长 PIN（默认 **1234**）即可进入控制页

> 二维码由 ZXing 根据电视当前 IP 实时生成，IP 变了会自动重画。
> 端口默认 8080，被占用时自动回退到 8081/8082/8083，以设置页显示的实际地址为准。
> 如果电视和手机不在同一网段、或路由器开了「AP 隔离」，会连不上。

### 把控制页放到手机桌面

控制页带 PWA 支持（manifest + 各尺寸图标），扫一次码后添加到桌面，以后点图标直接打开，不用再扫码或输网址：

- **iPhone（Safari）**：点底部分享按钮 → 「添加到主屏幕」→ 添加。添加后全屏无地址栏，体验最像 App
- **安卓（Chrome / Edge / 各品牌浏览器）**：右上角 ⋮ 菜单 → 「添加到主屏幕」/「安装应用」→ 确认
- **微信里打开的**：微信内置浏览器不支持，先点右上角 ··· →「在浏览器打开」

控制页底部也有按机型自动切换的操作引导。

> 局域网是 `http` 不是 `https`：iPhone 添加后可全屏；安卓部分浏览器只存成带图标的书签快捷方式，能一键打开但可能保留地址栏，属正常现象。
> 电视 IP 变了（比如换路由器）需要重新扫码并重新添加一次。

### 手机上能做什么

| 分类 | 操作 |
| --- | --- |
| 状态 | 实时查看是否已锁屏、剩余时间、每日时长、解锁题数、开机自启、亮屏自动计时（3 秒自动刷新） |
| 快捷 | 立即锁屏、立即解锁、停止计时 |
| 时长 | 15/30/45/60/90/120 分钟一键设置并开始计时；临时 +5/+10/+30 分钟 |
| 配置 | 改解锁题数、开关开机自启、开关亮屏自动计时、修改家长 PIN |

**锁屏中加时**会自动解锁，并按加时时长重新计时。

### 安全性

- 所有控制接口都必须带家长 PIN，PIN 只存在手机浏览器本地，不上传
- 复用锁屏界面的防爆破机制：连续 5 次错误 PIN 锁定 30 秒
- 服务只监听局域网，不对外网开放；不需要账号、不需要云服务
- 设置页可一键关闭手机控制

## 锁屏防绕过机制

- 锁屏时显示全屏悬浮窗覆盖层，遮挡桌面
- 按遥控器 HOME 键 → 被悬浮窗拦截，无法回到桌面
- 按返回键 → 无效
- 关机重启 → 锁屏界面自动弹出
- 计时器与锁屏状态保存在 SharedPreferences 中，重启不丢失

│       ├── layout/                   # 布局XML
│       ├── drawable/                 # 按钮选择器、图标、TV banner

## 技术参数

- 最低支持：Android 5.0 (API 21)
- 目标版本：Android 13 (API 33)
- 编译版本：API 34
- 签名密钥有效期：10000天
- 架构：armeabi-v7a / arm64-v8a（覆盖所有小米电视）
- 当前版本：v1.2.0（versionCode 5）

## 编译方法

```bash
# 需要 JDK 17 和 Android SDK
export JAVA_HOME=<JDK路径>
export ANDROID_HOME=<SDK路径>

gradle assembleRelease

# 签名（使用自己的 keystore）
zipalign -f 4 app-universal-release-unsigned.apk aligned.apk
apksigner sign --ks <你的.keystore> --out kidslock-release.apk aligned.apk
```

> 已发布的 kidslock-release.apk 由作者签名，如需自行编译发布请替换为自己的签名密钥。

## 注意事项

- 安装后需在电视设置中给予「开机自启」和「后台运行」权限
- 手机控制依赖常驻前台服务，若被系统清理，打开一次设置页即可重新拉起
- 小米电视的「安全中心」可能会清理后台，需将本应用加入白名单
- 部分小米电视系统可能限制 HOME launcher 替换，如遇问题请使用家长PIN解锁
- 汉字题库包含约 140 个五年级水平汉字，随机出题
